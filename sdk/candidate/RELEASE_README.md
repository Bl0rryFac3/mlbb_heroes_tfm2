# MLBB Heroes 1.1.165 Windows playtest

Yu Zhong joins as hero 27. Requires **Teamfight Manager 2 0.7.3 or newer on Windows**. The Mods menu shows **1.1.165**.

Close the game and move the previous `mlbb_heroes` folder outside the game's `mods` folder. Extract the ZIP straight into `mods`. Verify `mods/mlbb_heroes/mod.mod_info`, then enable MLBB Heroes in the main menu. The included `Install_Guide.html` has screenshots.

Look for Yu Zhong in the Melee category and hover his draft card. In a match, test his marks, Dragon Tail, Soul Grip followed by Furious Dive, and the Black Dragon and Dragonoid transitions. The matching source archive contains a focused playtest checklist.
