# MLBB Heroes v2.9.0

Lesley joins the roster with empowered rifle shots, camouflage, a defensive grenade, and a four-round ultimate. Includes updated Yu Zhong and Chou combos.

Extract `mlbb_heroes` into the game’s `mods` folder and enable MLBB Heroes. The Mods menu shows **1.1.174**. Requires Teamfight Manager 2 0.7.3 or newer on Windows.
