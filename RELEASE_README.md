# MLBB Heroes v2.8.0

Adds Yu Zhong, a melee fighter who builds Sha Residue to damage enemies and restore health. His ultimate lets him fly as the Black Dragon before landing in Dragonoid Form, where his skills reach farther.

Extract the `mlbb_heroes` folder into the Teamfight Manager 2 `mods` folder and enable MLBB Heroes in the game. The Mods menu shows build **1.1.170**. The pack requires Teamfight Manager 2 v0.7.3 or newer.
