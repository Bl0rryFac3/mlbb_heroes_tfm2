# MLBB Heroes v2.7.0

Atlas joins as hero 26. This release also includes balance updates for Granger, Hanzo and Eudora, and restores the animated hover previews for layered heroes in the match ban/pick grid.

Requires **Teamfight Manager 2 0.7.3 or newer on Windows**. The Mods menu shows **1.1.164**.

Close the game and move the previous `mlbb_heroes` folder outside the game's `mods` folder. Extract the ZIP straight into `mods`. Verify that `mods/mlbb_heroes/mod.mod_info` exists, then enable MLBB Heroes in the main menu. Open the included `Install_Guide.html` for screenshots.
