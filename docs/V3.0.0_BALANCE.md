# MLBB Heroes v3.0.0 balance changes

Windows x64 · Teamfight Manager 2 0.7.3+ · Internal build 1.1.179 · Comparison build 1.1.178

## Individual changes

- Angela basic range 88,000 → 80,000. Basic cadence 60 → 90 ticks. Keep healing and shielding formulas for the first trial.
- Alpha Force Swing physical flat damage 120 → 100. Existing coverage, one heal per cast, and Beta’s damage types carry over. Tooltips report the actual three-hit trigger and physical versus true damage.
- Balmond Cyclone Sweep flat damage per hit 30–55 → 24–44. The 14 hit opportunities and armor shred carry over.
- Eudora Forked Lightning keeps signed direction at the map boundary, counts overlapping minion hit circles, and rechecks AI fallback aim. Damage formulas carry over.
- Franco Iron Hook flat damage 220 → 190. Pull, stun and suppression timing carry over.
- Johnson Impact Wrench flat damage 70 → 80. 110% armor scaling carries over.
- Lesley Lethal Shot champion true damage 75 + 125% Attack → 75 + 110% Attack. Lane and jungle damage keeps its physical 125% ratio. Three original skill icons and current ability descriptions are included.
- Aldous, Estes, Fanny, Gusion and Lancelot now declare the same starting Attack their stack handlers already apply. Their native HP writers use the new HP values. Kupa’s bonus-HP calculation uses Popol’s new baseline so the 40 base HP increase applies to Popol alone.

## Windows playtest

1. Check the Mods menu for 1.1.179. Load a draft and a match, including Lesley’s three skill icons and tooltips.
2. Test Angela against a turret and paired with Atlas using the tester’s item setup. Check basic range, attack interval and ability uptime.
3. Test Eudora with overlapping minions, near the cone edges, with both facings and near terrain. Check her existing damage and links.
4. Test Alpha against 700–800 and 900–1,100 HP targets. Check Force Swing, normal Beta strafes, and both phases of the ultimate.
5. Compare tank survival, Franco hook conversion, Johnson engage, Balmond short and full spin, and Lesley true shots against champions and physical shots against other targets.
6. Verify the five stack-based stat writers at spawn, level-up and respawn. Check Kupa’s bonus HP and Zhask’s inherited spawn HP separately.
7. Compare similar drafts at levels 1, 6, and 12 with identical item and save-patch settings. Use the previous build for rollback.

Lesley icon attribution is recorded in `source/lesley/icons/SOURCES.json`.
