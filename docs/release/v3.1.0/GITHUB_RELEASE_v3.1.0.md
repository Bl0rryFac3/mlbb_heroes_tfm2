## New hero — X.Borg

X.Borg joins the roster as hero 31. He fights in armored and armorless forms. This release includes his selection idle, combat animations, skill effects, official skill icons, and 29 default English voice clips.

| Base stat | Level 1 | Growth per level |
| --- | ---: | ---: |
| HP | 880 | +100 |
| Attack | 96 | +6 |
| Defense | 33 | +5 |
| Magic Resistance | 25 | +3 |
| Move Speed | 1,040 | +4 |

- **Firaga Guard.** While armored, X.Borg takes 20% less damage and incoming damage drains a separate Firaga reserve. The bar above him shows reserve while armored and recharge while armorless. Basic hits and skill hits build heat on enemy champions and monsters. Skill hits deal true damage to targets already at four stacks. Supplies restore reserve or recharge.
- **Fire Missiles.** X.Borg can move while firing up to six pulses in a cone. The armorless flame reaches farther in a narrower cone and deals 60% damage. Damage to champions and monsters restores body HP and adds Firaga reserve or recharge energy. Cooldown is 5 seconds.
- **Fire Stake.** Five stakes return after 1.2 seconds, hitting and pulling each enemy once and retrieving supplies. The armorless fan has longer reach. Cooldown is 10 seconds.
- **Last Insanity.** While armored, X.Borg charges and spins for up to 3 seconds. The detonation deals 100 + 6% of the target's maximum HP as true damage, increased by 50% against overheated targets. Damage to epic monsters is capped at 150. An armor break triggers a half-strength blast. Cooldown is 44 seconds.
- Both forms can use normal basic attacks against enemy towers and the Nexus.

## Other changes since v3.0.1

- **Fanny** can plan up to three cable anchors ahead, including sideways setups. Steel Cable can target movement waypoints for rotations and retreats. Individual hooks still reach 165,000 game units.
- **Aldous** has updated idle, movement, attack, skill, ultimate, hit, and death animations. Chase Fate uses a rotating drill during the charge and a recovery animation on arrival.
- **Balmond** has updated sprites and a visible Cyclone Sweep effect. The three-second sweep can follow its target while spinning.

## Installation

Use the Windows asset `mlbb_heroes_v3.1.0.zip`. Extract the `mlbb_heroes` folder into the game's `mods` folder and enable MLBB Heroes. The in-game build is **1.1.201**, playtested on **Teamfight Manager 2 0.7.4**. The ZIP includes a screenshot guide.
