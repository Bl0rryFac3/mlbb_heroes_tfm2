**MLBB Heroes v3.1.0 — X.Borg**

X.Borg joins as hero 31, with armored and armorless forms, a Firaga gauge, official skill icons, and 29 default English voice clips.

- **Fire Missiles** hits enemies in a moving cone, builds heat, and restores body HP and Firaga.
- **Fire Stake** recalls five stakes to pull enemies and collect supplies.
- **Last Insanity** spins for up to 3 seconds and deals more blast damage to overheated targets.

This update also adds Fanny's three-anchor cable planning, new Aldous animations, and Balmond's updated Cyclone Sweep visuals.

Windows · Tested on TFM2 0.7.4 · In-game build 1.1.201
