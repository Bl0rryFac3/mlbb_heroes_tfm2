## New hero — Minotaur

Minotaur joins the roster as hero 32. He has combat animations, an animated champion-select idle, official ability icons, and four English voice cues.

- **Rage Incarnate** restores a portion of HP lost to enemy champions for three seconds after a skill cast. Recovery doubles while Enraged.
- **Despair Stomp** leaps to a landing point, knocks up nearby enemies, and empowers the next two eligible basic hits. The landing shockwave widens while Enraged.
- **Motivation Roar** heals Minotaur and the nearby ally with the lowest HP percentage for 220 + 60% Magic Power. Minotaur also recovers 8% of his missing HP. While Enraged, the roar heals every nearby allied champion.
- **Minoan Fury** slams three times. The first two hits each deal 65 + 40% Attack physical damage and slow. The final hit deals 100 + 55% Attack true damage and knocks enemies airborne. Enraged lasts 12 seconds from activation.

## Smaller download

The voice bank keeps one recording per retained cue. Combat sound effects are preserved. The Windows ZIP is about **38 MB**, down from about **84 MB** in v3.1.0.

## Installation

Extract `mlbb_heroes_v3.2.0.zip` into the game's `mods` folder. If upgrading, move the old `mlbb_heroes` folder out first to clear unused audio files. Enable MLBB Heroes in the Mods menu and check for build **1.1.204**. The Windows package was playtested on **Teamfight Manager 2 0.7.4**.
