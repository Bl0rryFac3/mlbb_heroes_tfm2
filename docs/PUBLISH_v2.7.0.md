1. Open the [GitHub release editor](https://github.com/Bl0rryFac3/mlbb_heroes_tfm2/releases/new?tag=v2.7.0) and choose the intended release commit in the tag target.
2. Set the release title. Paste `GITHUB_RELEASE_v2.7.0.md` from the “New hero” heading onward.
3. Attach `mlbb_heroes_v2.7.0.zip` as the Windows install. The full source ZIP is available as a separate optional development download. The checksums cover both ZIPs.
4. Publish as the latest stable release. Check that the release page and install asset open, then use `DISCORD_v2.7.0.md` if announcing it.
