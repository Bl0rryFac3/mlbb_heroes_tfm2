# Gusion default skill icon sources

The original files below were downloaded from the default ability-icon files linked by the Gusion page on Mobile Legends Wiki/Fandom on 2026-10-23. The CDN returned WebP payloads even though the canonical wiki file URLs end in `.png`; the originals are retained with their actual `.webp` extension. Runtime PNGs are 64×64 Lanczos resizes, with filenames mapped as follows:

- `Sword_Spike.webp` → `icons/gusion_skill.png` (Skill 1)
- `Shadowblade_Slaughter.webp` → `icons/gusion_skill2.png` (Skill 2)
- `Incandescence.webp` → `icons/gusion_ult.png` (Ultimate)
