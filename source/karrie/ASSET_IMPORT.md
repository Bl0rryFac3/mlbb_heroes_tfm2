## Agreed visual/mechanical mapping

- Basic attack uses the small hand-lightwheel projectile.
- Skill 1 uses the same ring/spike motif through travel and its transient impact; the slow is applied by the projectile/skill behavior, not a separate unrelated zone asset.
- Skill 2 reuses the basic projectile; it fires at the nearest valid enemy after the dash, and does not spawn a projectile if there is no valid target.
- Ultimate uses the supplied one-shot activation ring, retains the normal single-lightwheel projectile, and adds attack speed; no paired-wheel projectile or persistent Gusion-style marker is used.

## v1.1.22 localization presentation

Karrie’s attack, passive, Skill 1, Skill 2, and Ultimate descriptions now use the same rich-text color and stat-icon conventions as the other heroes in all five locales. Skill 1 wording explicitly says its impact is brief and no slow zone lingers; the 35% slow still lasts one second. No stat values, damage formulas, durations, or cooldowns changed in this pass.

## v1.1.23 Skill 1 zone, Ultimate, and audio routing

Skill 1 now keeps a stationary violet ring zone for 90 ticks (1.5s). Two native pulses are queued at 30 and 60 ticks; each deals 10 + 10% AD physical damage to valid non-tower enemies in the existing radius and refreshes the 35% slow for 35 ticks. Zone pulses do not apply additional Lightwheel Marks. The reusable 64×79 ring frame is generated by `source/karrie/make_skill1_slow_zone.py` from the existing impact atlas. The Ultimate remains 360 ticks (6s) with +20% movement speed; its attack-speed bonus is now +30%, and the 1200-tick (20s) cooldown is unchanged.

For voice events with available assets, the `.sound_info` event IDs remain stable while the WAV clip IDs have been given distinct `*_sfx_vo_*` names; `mod.override_info` now routes both the event and clip IDs to the mod-local assets. This avoids the same-ID sound/clip failure pattern found during the audit. Existing skill voice coverage is limited: Fanny has no Skill 1 voice asset, Aldous has no Skill 1/2 voice assets, and Estes reuses one skill line for both Skills 1 and 2. No replacement voice lines were synthesized.

## v1.1.24 full audio wiring

The audio pass now routes every bundled custom voice/SFX event for Fanny, Lancelot, Estes, Aldous, and Gusion; event IDs and playback clip IDs are distinct and both are present in `mod.override_info`. Native passive hooks play available selection/idle and movement/run lines, plus Estes death variants. Karrie Hawkwatch OGG files from the user-provided Fandom page are preserved in `source/audio/karrie_hawkwatch/`; selection/idle, eight movement lines, two death lines, Skill 1, Skill 2, and both sequential Ultimate lines have independent event/clip routes. No missing voice clips were fabricated. The API has no pre-match selection-screen hook, so selection audio runs on spawn; movement/idle are inferred from periodic position changes. This is source/package wiring, not proof of audible in-game playback.

## Prototype status

A working-tree prototype now includes `champion/mlbb_karrie.data_champion` and `src/karrie.rs`, registered from `src/lib.rs`. After loader corrections, Karrie's category is the accepted `Range` enum and tags are `['AD', 'Range']`. The v1.1.21 VFX pass makes the basic projectile slightly smaller, the Skill 1 ring slightly larger, and the passive mark slightly smaller while raising its artwork using a tall bottom-anchored frame and Gusion-style `view_buffs`. The previous mark packer omitted the horizontal frame offset, overlaying all six stack images into the first cell and leaving the rest empty. The packer is fixed; the active mark atlas is regenerated directly from the original source so mark_1 through mark_6 are distinct nonblank stages. The Ultimate action now requests an `Enemy` target (including towers) as its AI trigger, while its native effect buffs Karrie herself. It grants +20% move speed and +20% attack speed for 6 seconds, keeps the single-wheel projectile, and no longer uses paired-wheel art. A positive expected-damage hint is also supplied to the AI. These are source-level changes; runtime use still needs in-game verification. The basic attack handler no longer repeats the action range check at projectile-start, so a moving target stepping beyond the boundary won't suppress the launched wheel. The balanced draft uses: 5 marks; a 4% max-HP + 10% AD true-damage proc (250 hero / 300 jungle-epic cap); a 35% one-second Skill 1 slow; a 42,000-unit Skill 2 dash that searches for a valid enemy and fires nothing when none is nearby; and a 6-second Ultimate with +20% move speed and +20% attack speed; it keeps basic attacks at 100% AD and uses the normal single-lightwheel visual. These numbers and movement timings are provisional TFM2 balance choices, not verified live-server values.

Fandom default skill icons were downloaded/transcoded from `https://mobile-legends.fandom.com/wiki/Karrie` (the `Lightwheel Mark`, `Spinning Lightwheel`, `Phantom Step`, and `Speedy Lightwheel` images). The original Karrie icon assets are 100×100 PNGs in `icons/`.

Rust formatting passes; Linux `cargo test --release` passes (20 tests), and both Linux and Windows x86-64 GNU release builds succeed. A Windows-target test executable also compiles (`cargo test --target x86_64-pc-windows-gnu --no-run`); it was not run. The Windows DLL was verified as PE32+ x86-64 with the stable-mod entry exports and is included in `mlbb_heroes_v1.1.21_windows_x64_karrie_candidate.zip`; a Linux `.so` v1.1.21 candidate is also packaged separately. Static JSON, atlas-frame bounds, alpha-channel, asset-path, and native visual-alias checks pass. The existing project-root Windows DLL was intentionally left untouched; it predates Karrie. No TFM2 executable/install was available here, so no in-game launch or match test was performed. Do not describe the prototype as runtime-tested or TFM2-playable until the package is tested in TFM2.
