# Atlas action media sources

The three active PNGs are copied to the corresponding named Atlas icon slots. Frigid Breath is a passive reference image. [Atlas abilities](https://mobile-legends.fandom.com/wiki/Atlas)

The default English Annihilate and Fatal Links OGG files are decoded as mono 44.1 kHz signed 16-bit PCM. [Annihilate source](https://static.wikia.nocookie.net/mobile-legends/images/d/d9/Atlas.skill.ogg/revision/latest) · [Fatal Links source](https://static.wikia.nocookie.net/mobile-legends/images/d/d2/Atlas.ult.ogg/revision/latest) · [Voice index](https://mobile-legends.fandom.com/wiki/Atlas/Audio)

The two Perfect Match sound effects are original mod audio. `tools/build_atlas_sfx.py` reproduces them. The original game artwork and recordings belong to their rights holders.
