# Lancelot source/asset notes

This folder preserves supplied source inputs used by the `mlbb_heroes` runtime package. Runtime assets are under the package's `sprite/`, `effects/`, and `icons/` folders; the `.data_champion` references them through `asset/mlbb_heroes/...`.

- `lancelot_atlas.json`: supplied frame/pivot manifest for the 8-row character sheet.
- `target ring mark.png`: supplied Puncture sword-mark/ring source, retained as a standalone downloadable PNG.
- `lance-skill1_source.png`: supplied Skill 1 character-frame source.
- `lancelot_*.webp`: supplied skill/passive icon references.
- `vfx_originals/`: supplied high-resolution VFX source images.
- `asset_manifest.json`: source-to-runtime path map and sheet dimensions.

The runtime `hit` animation is still the previously delivered idle-derived placeholder. No replacement hit art is included here.
