MLBB Heroes v3.0.0 contains 29 heroes and uses build 1.1.179. Requires Teamfight Manager 2 0.7.3 or newer.

The Rust crate is in sdk/candidate and the matching stable SDK is in sdk/mod-api-stable. Run cargo test --locked --manifest-path sdk/candidate/Cargo.toml. The bundled DLL targets Windows x64.

Install the mod with mlbb_heroes_v3.0.0.zip. See docs/V3.0.0_BALANCE.md for the roster changes and Windows playtest checklist. Lesley's original skill icon sources and attribution are in source/lesley/icons.
