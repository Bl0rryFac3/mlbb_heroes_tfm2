Install MLBB Heroes

Teamfight Manager 2 on Steam for Windows · MLBB Heroes v3.1.0 · X.Borg · 31 heroes

Playtested on Teamfight Manager 2 0.7.4. The in-game Mods menu shows build 1.1.201.

What a correct install looks like

Teamfight Manager 2
└── mods
    ├── mlbb_heroes
    │   ├── mod.mod_info
    │   └── mlbb_heroes.dll
    └── mlbb_items  (optional)

Each pack has its own folder directly inside mods. Open mlbb_heroes and check that mod.mod_info and the DLL are immediately visible.

Install on Windows

  1. Download the Heroes ZIP

    Use mlbb_heroes_v3.1.0.zip. The ZIP opens directly to mlbb_heroes.

  2. Open the game’s mods folder

    Close the game. In Steam, right-click Teamfight Manager 2 and choose Manage → Browse local files. Open mods. When updating, move the old mlbb_heroes folder to a backup location outside mods.

  3. Extract the mod folder into mods

    Extract the release ZIP directly into mods. In WinRAR, choose Extract Here if the archive is already in mods, or Extract files… to choose that destination. With Windows Extract All…, change the destination to the exact mods folder.

    If extraction creates a versioned folder, open it and move the inner mlbb_heroes folder into mods. You should end up with mods\mlbb_heroes\mod.mod_info.

  4. Enable the pack

    Start the game, open Mods, and enable MLBB Heroes. Check that the entry shows 1.1.201.

Find heroes and items in-game

  • Heroes. Enter a match draft and look for the added champions in the pick and ban pool. Look for X.Borg in the Melee category and hover his portrait to see his idle animation and skills.
  • Items. If you also installed MLBB Items, enable it in Mods. In your career, open Tactics → Builds to customize builds, or use Check Item Info to browse items and recipes. If the items are missing in a new career, save, return to title, then reload.
